JellyDRTV
Features Install GitHub

All of DRTV, inside your Jellyfin.

A Jellyfin plugin that adds DR's series, films and programs to your library. Stream them in any Jellyfin app, watch DR's channels live, and download what you want to keep.

Install the plugin View on GitHub

What it does

Stream everything

Every series, film and program on DRTV shows up in Jellyfin with its title, description, poster and episode pictures. Press play and it streams straight from DR, with Danish subtitles.

Download what you want to keep

Episodes, whole seasons, whole series, films or programs. Downloads take the place of the stream in your library and stay when DR removes the title.

Follow series

Follow a series and new episodes are downloaded automatically. The plugin checks every two hours.

Favourite = download

Mark something as favourite in any Jellyfin app, on your phone, TV or browser, and it's downloaded. A favourited series is also followed.

DRM titles are marked

Some bought-in titles are DRM-protected and can't be played outside DR's own apps. They get a red DRM badge, so you know before you press play.

Live TV with a guide

DR1, DR2, DR Ramasjang and TVA show up in Jellyfin's Live TV with DR's full TV guide. Record a programme with Jellyfin's DVR and it lands in your recordings.

Keeps itself up to date

A nightly sync adds new titles and removes what DR took down, but never your downloads. Series that haven't changed are skipped, so it stays light on your server.

How it works

The plugin writes DRTV's catalog into a folder as small placeholder files that Jellyfin reads like normal media. When you press play, the plugin asks DR for the stream right then, so links never go stale.

Install

  1. In Jellyfin, open Dashboard → Plugins → Repositories and press +. Add this address:
    https://raw.githubusercontent.com/MightyX3N/JellyDRTV/main/manifest.json
  2. Open Catalog, find JellyDRTV and install it.
  3. Restart Jellyfin.

Needs Jellyfin 12.4 or newer. yt-dlp, which does the downloading, is fetched and kept up to date by the plugin.

Set up

  1. Open Dashboard → Plugins → JellyDRTV, set the Library folder and save. On Docker or a NAS, use the folder's path inside the container, e.g. /media/drtv, and map it read/write.
  2. Press Sync DRTV catalog now. The first sync takes a while; after that it runs every night.
  3. Add three libraries in Dashboard → Libraries:
    TypeFolder
    Shows…/Serier
    Movies…/Film
    Movies…/Programmer

Good to know

  • Denmark only. DR only sends its streams to Danish connections, so your Jellyfin server has to be in Denmark. The plugin doesn't try to get around that.
  • DRM titles can't be played. They stay in your library, marked with a red badge, but neither Jellyfin nor the plugin can play or download them.
  • Downloads are for private use. Keep them for yourself; don't share them.
  • Not made by DR. JellyDRTV is an independent, open-source project and isn't affiliated with DR. It uses the same public web API as dr.dk/drtv.
JellyDRTV is open source. Code, issues and updates are on GitHub.
